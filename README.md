# 🌸 Emplora – Employee Management Dashboard

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/ebruakdemir/employee-management-dashboard.git
```

### Backend

```bash
cd backend/EmployeeManagement.Api
dotnet restore
dotnet run
```

The API will start on:

```
http://localhost:5215
```

---

### Frontend

```bash
cd frontend
npm install
ng serve
```

Open:

```
http://localhost:4200
```
