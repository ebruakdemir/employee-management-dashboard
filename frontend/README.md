# Emplora Frontend

This folder contains the Angular frontend for the Emplora Employee Management Dashboard.

## Technologies

- Angular
- TypeScript
- HTML
- CSS
- Angular Forms
- Angular HttpClient

## Features

- Employee dashboard
- Company statistics
- Search and filtering
- Sorting
- Pagination
- Create, update and delete employees
- Responsive design
- Dark and light mode

## Run

```bash
npm install
ng serve
```

Open:

```
http://localhost:4200
```

The frontend communicates with the ASP.NET Core Web API running on:

```
http://localhost:5215
```
